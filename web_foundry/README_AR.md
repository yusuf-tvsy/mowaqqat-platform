# Web Foundry 6 — قالب تطوير عربي مستقل

هذا نموذج MVP لبداية المستوى 6 (Internal Developer Platform) **وليس منشئ تطبيقات متعدد المستأجرين أو خدمة نشر جاهزة للإنتاج**. جميع وظائفه محلية بلا اتصال بالإنترنت، ودون API keys أو بيانات حقيقية أو نشر.

## التشغيل

```bash
python web_foundry/foundry.py init --slug demo-site --title 'موقع تجريبي' --out /tmp/demo-site
python web_foundry/foundry.py audit --site /tmp/demo-site
python web_foundry/foundry.py gate --manifest /tmp/demo-site/project.json
python -m unittest discover -s web_foundry/tests -v
```

أمر `gate` يرجع رمز خروج 2 لأن الشواهد والاعتمادات لم تُثبت بعد؛ **هذا نجاح للضابط وليس خطأً في التوليد**. إذا كانت الأدلة داخل الملف تشير إلى نجاح، فيكون القرار فقط `READY_FOR_EXTERNAL_APPROVAL`: لا يُسمح بالنشر دون تحقق مستقل من خدمة الاستضافة ومن القائم بالاعتماد.

## ما يقدمه
- إنشاء موقع ثابت عربي بسيط مناسب للتجربة (RTL وإتاحة أساسية وتجاوب)، دون تسجيل دخول ولا بيانات حية.
- إنشاء `project.json` يسجل تصنيف البيانات ومرجع المصدر وحالة كل ضمان للنشر.
- فحص الوسوم الأساسية والروابط المحلية والصور والروابط الداخلية دون شبكة.
- اختبارات وحدات وحماية ضد تجاوز المسارات واستبدال وجهات موجودة.
- GitHub Actions بحد صلاحيات `contents: read`، **دون أي خطوة نشر**.

## ما لا يقدمه
لا يصلح لتشغيل قواعد بيانات أو مستودعات خاصة أو تسجيل دخول أو إدارة حسابات الطلاب/الموظفين. لا يثبت WCAG AA أو الأداء الفعلي أو أمان تطبيق كامل؛ هذه اختبارات لاحقة. لا تنقل إليه مصادر كادر أو بيانات مراكز البحث أو الأكاديمية. لا تنشره بوصفه موقعًا مؤسسيًا دون اعتماد الهوية والمحتوى وسياسات الخصوصية.

## مسار التوسع
القالب التالي يضيف تصنيف مشاريع، وموصلات API بخيارات آمنة، واختبارات E2E، ومخزن أسرار منفصل، وإدارة مصدر خاص، وبيئات staging، ومقاييس SLO؛ قبل الانتقال إلى أي أتمتة نشر. انظر الخطة الرئيسية داخل ChatGPT Space.
